Shipshape

Go cli that reads yaml-based policies and runs them against a directory.

Quick Start →

Cross-platform

Binaries are available for Mac & Linux, on amd64 & arm64

Flexible output

Choose between simple (for humans), json, junit or table, according to your needs

Shipshape supports two configuration formats — the 1.x pipeline (collect / analyse / output) and the legacy 0.x checks: format. The same binary runs both. See Config versions.
